# ottaviae.github.io

Personal website, built with [Quarto](https://quarto.org).

- Edit the `.qmd` pages; preview them in RStudio with **Render** or `quarto preview`.
- The site is rendered into `docs/`: render, commit and push. On GitHub, Pages publishes from branch `main`, folder `/docs`.
- Slides stay in the `presentations` repository: the Talks page links to them.
